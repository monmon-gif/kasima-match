# 楽天アフィリエイトの登録

全ページの本文の下、フッターの直前に、共通で最大3件表示します。共通レイアウトで1回だけ描画します。
商品未登録の初期状態では、枠全体を表示しません。試合JSONの編集は不要です。

## 登録するもの

1. `offers.json` の `rakuten-poncho` に観戦用レインポンチョを登録。
2. `rakuten-uniform` に鹿島アントラーズの26–27ホームレプリカユニフォームを登録。
3. `rakuten-cushion` にBears Rockの携帯座布団・エアクッションを登録。

楽天で発行した広告リンクのURLを `linkUrl` に入れ、`enabled` を `true` にします。
HTML全体ではなく、リンクの `href` の値を登録してください。
HTML内の `&amp;` はURLとしての `&` に戻します。計測用パラメータは維持してください。
HTTPSの `hb.afl.rakuten.co.jp` と短縮URLの `a.r10.to` に対応します。
別のホストが発行された場合は、正規の楽天リンクか確認してサービスの許可リストを更新します。

タイトルと説明は選んだ商品の実際の仕様に合わせて更新してください。
画像を表示する場合は、楽天発行HTMLの画像URLを `imageUrl`、画像の説明を `imageAlt` に登録します。画像URLの計測用パラメータも維持してください。画像なしのテキストカードにも対応しています。
HTMLをそのまま実行する機能はありません。

配列の順番が掲載順です。`enabled: false` に戻すと掲載を停止できます。
無効なURLの案件は表示しません。試合の開催状態にかかわらず、トップ・試合・選手・ランキングなど全ページで表示します。
本番への反映には再ビルド・デプロイが必要です。

## 確認

- 未登録時に広告枠と空のボタンが出ないこと。
- 有効な案件だけが、ポンチョ→ユニフォーム→クッションの順で最大3件表示されること。
- トップ・開催予定／終了済み試合・選手・ランキングの各ページ下部に、PR表記付きの枠が1つだけ表示されること。
- スマホ幅では縦に並び、キーボードでもリンクに移動できること。
- 広告リンクは楽天発行のURLを保ち、新しいタブで開くこと。
